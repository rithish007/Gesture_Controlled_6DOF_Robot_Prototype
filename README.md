# Gesture Controlled Robot Prototype
## Overview
This project presents a gesture-controlled 6-degree-of-freedom (6DOF) robotic manipulator that provides a prototype for human robot interaction using computer vision. The system interprets hand gestures and translates them into real time robotic movements.

## Objectives
- Develop a 6DOF robotic arm using subtractive manufacturing.
- Implement gesture recognition using computer vision.
- Enable real-time control of the manipulator.
- Integrate hardware and software into a unified system

## How It Works
- A camera captures hand gestures
- Computer vision processes and identifies gestures
- Detected gestures are mapped to robot movements
- Commands are sent to the microcontroller
- The robotic arm executes the motion

## Getting Started
